# Getting Started

Four paths to first request, ranked from shortest feedback loop:

| Path | Time | Use it for |
|------|------|------------|
| [On-device demo](/getting-started/on-device) | 60 s | Verifying the binary works on your machine before anything else. |
| [Quickstart](/getting-started/quickstart) | 5 min | Spinning up the gateway against a single OpenAI-compatible provider. |
| [Install](/getting-started/install) | 15 min | Production-grade install (Docker Compose, bare metal, K8s). |
| [Deploy](/getting-started/deploy) | 30 min | HA / multi-node / production cutover. |

If this is your first time: run the on-device demo first, then come back here for install.
