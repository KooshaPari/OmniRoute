# Demo

GUI/visual walkthrough and stress test programs. Run them on-device.

| Program | Path | Use it for |
|---------|------|------------|
| [GUI Walkthrough](/demo/gui) | `demo/gui-walkthrough.ts` | Visualizing routing decisions, request flow, failovers. |
| [Stress Test](/demo/stress-test) | `demo/stress.ts` | Burst-load + sustained-load verification of p99 targets. |
| [On-device](/demo/on-device) | `demo/on-device.sh` | 60-second smoke test on any machine. |
