# Environment Variables

| Variable | Default | Purpose |
|----------|---------|---------|
| `OMNIROUTE_PORT` | `20128` | Listen port |
| `OMNIROUTE_DB_PATH` | `./data/omniroute.db` | SQLite location |
| `OMNIROUTE_LOG_LEVEL` | `info` | `debug`, `info`, `warn`, `error` |
| `OMNIROUTE_AUDIT_DIR` | `./audit` | Hash-chained audit log dir |
| `OMNIROUTE_DISABLE_TELEMETRY` | `false` | Disable first-party telemetry |
| `OMNIROUTE_PROVIDER_PLUGIN` | (unset) | Path to a provider manifest to load |
